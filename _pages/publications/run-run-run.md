*Run Run Run: Programs + Computer-Generated Texts* is a collection edited by Nick Montfort and published by Bad Quarto, featuring contemporary computational poetry and digital literature.

The computer programs in this collection were written without AI assistance.

These booklets were printed, collated, folded, and staple bound by hand.

Open edition; 1st printing of 100 copies, June 2025.
